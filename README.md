# Rinari

Claude の利用上限と、モデル別の使用割合をブラウザで確認できる自分専用のダッシュボードです。
パソコンの中だけで動き、`http://127.0.0.1:8765/` で開きます。

- **利用上限**: 5時間枠・週間枠（全モデル）・モデル別の週間枠（Fable など）の使用率とリセット時刻
  - 枠ごとの推移グラフと、今のペースが続いたときの予測（リセット時の使用率、または上限に達する時刻）
  - 枠の期間中に使ったモデルの内訳（料金換算）と、使用率 1% あたりの料金換算
  - 週間枠の「今日の目安」（残りをリセットまでの日数で均した、今日使ってよい量）と今日の使用量
  - ブラウザのタブのタイトルに 5時間枠の使用率とリセットまでの時間を表示
- **チャット・Cowork の利用（推定）**: 上限の % のうち、会話ログに残らない利用（claude.ai のチャット、ログの残らない Cowork）の分を推定して、枠ごと・日ごと（直近7日）に表示
- **5時間枠の始まる時刻**: 時間帯ごとの使い方から、何時に枠を始めておくと1つの枠への集中が減るかを提案
- **モデル別の使用割合**: 期間（今日／7日間／30日間／全期間）と値（全トークン／出力トークン／応答数／料金換算）を切り替えて表示
  - API 料金換算の合計と1日あたり、割合バー、日別の推移、曜日×時間帯のヒートマップ（日曜日始まり）、モデル別・プロジェクト別・会話別の内訳
  - キャッシュの効率（キャッシュ読込率と、キャッシュによる節約額）
  - CSV の書き出し（日別×モデル×プロジェクト、会話別）
- **振り返り**: 今週・今月と前の期間との比較、週ごと（直近12週）・月ごと（直近12か月）の推移
- **通知とタスクトレイ**（Windows）: 使用率が 80%／95%／100% になったとき、このペースだと30分以内に上限に達しそうなとき、枠がリセットされたとき（前の枠を50%以上使っていた場合）、利用上限を続けて取得できないときに Windows の通知を出します。トレイのアイコンには使用率の数字を出します
- **動作状態の表示**: 取得の失敗、ログインの期限切れ、会話ログが見つからないなどの問題を画面の先頭に表示します

各項目は見出しをクリックすると閉じられます（開閉の状態はブラウザに保存されます）。

Python 3.9 以上の標準ライブラリだけで動きます。追加のインストールは要りません。
exe や PowerShell のスクリプトは使わず、署名済みの `python.exe` / `pythonw.exe` と `.py` ファイルだけで動くので、Windows のスマート アプリ コントロールが有効でも止められません。

## 使い方

1. 先に Claude Code CLI でログインしておいてください（`claude` を起動して `/login`）。Rinari はそのログイン情報を使います。
2. `start.bat` をダブルクリックするか、このフォルダで次のコマンドを実行します（`rinari.pyw` をダブルクリックすると、ウィンドウを出さずに起動します）。

```bash
python -m rinari
```

ブラウザが自動で開きます。Windows ではタスクトレイに Rinari のアイコンが出ます。終了するときは、トレイのアイコンを右クリックして「Rinari を終了」を選ぶか、起動したウィンドウで `Ctrl+C` を押します。

タスクトレイのアイコン:

- ダブルクリック（または右クリック →「ダッシュボードを開く」）でダッシュボードを開きます。
- アイコンの数字は、いま一番効いている枠（無ければ一番高い枠）の使用率です。70% から黄、90% から赤になります。
- アイコンにマウスを乗せると、各枠の使用率が出ます。
- 右クリック →「通知をテスト」で通知の出方を確かめられます。通知が出ないときは、Windows の「設定 → システム → 通知」で「Python」の通知がオンになっているか確認してください（通知は Rinari を動かしている Python から出すため、送信元が Python と表示されます）。

| オプション | 内容 |
|---|---|
| `--port 番号` | 待ち受けるポート（既定: 8765） |
| `--no-browser` | 起動時にブラウザを開かない |
| `--no-tray` | タスクトレイのアイコンを出さない（通知も出なくなります） |

利用上限は5分ごと、使用割合は1分ごとに自動で更新します。「今すぐ更新」ですぐに取り直せます。同じポートで二重に起動しようとすると、メッセージを出して終了します。

### PC 起動時に自動で起動する

このフォルダで次のコマンドを一度実行すると、サインイン時に `pythonw.exe` でウィンドウを出さずに起動します（Windows の「スタートアップ」に Rinari を登録します）。

```bash
python -m rinari --startup on
```

- ブラウザは開かないので、`http://127.0.0.1:8765/` をブックマークしておくと便利です。
- フォルダを移動したときは、もう一度実行して登録し直してください。
- ウィンドウが無いので `Ctrl+C` では止められません。タスクトレイのアイコンから終了するか、PowerShell で次を実行します。

```powershell
Stop-Process -Id (Get-NetTCPConnection -LocalPort 8765 -State Listen).OwningProcess
```

- 自動起動をやめるときは、`python -m rinari --startup off` を実行します（「設定 → アプリ → スタートアップ」でオフにしても止まります）。
- 以前の手順でスタートアップフォルダに `Rinari.lnk` を置いた場合は、`Win+R` で `shell:startup` を開いてそれを削除してください（二重に起動しようとしても、2つ目はすぐ終了します）。

## 仕組み

- **利用上限**は Claude Code の `/usage` と同じ `https://api.anthropic.com/api/oauth/usage` から取得します。認証には Claude Code のログイン情報（`%USERPROFILE%\.claude\.credentials.json`）を使い、期限切れのときは Claude Code と同じ方法で更新して書き戻します（Claude Code はそのまま使い続けられます）。
- **モデル別の使用割合**は Claude Code の会話ログ（`%USERPROFILE%\.claude\projects\**\*.jsonl`）から集計します。同じ応答が複数行に記録されるので、メッセージIDで重複を除いています。
- Claude デスクトップアプリの Cowork が手元に残す会話ログ（`%LOCALAPPDATA%\Claude-Data\*\local-agent-mode-sessions\**\.claude\projects\**\*.jsonl`）も、「Cowork」というプロジェクトとして集計に加えます。残っているのは一部のセッションだけなので、Cowork の利用をすべては表しません。
- 環境変数 `CLAUDE_CONFIG_DIR` を設定している場合は、`.claude` の代わりにそのフォルダを使います。
- ログは大きくなるので、ファイルごとの集計結果を `%LOCALAPPDATA%\Rinari\stats-cache.json` にキャッシュし、変わったファイルだけ読み直します。
- **推移と予測**: 利用上限 API は過去の値を返さないので、Rinari は起動している間ずっと5分ごとに使用率を取得して `%LOCALAPPDATA%\Rinari\limits-history.jsonl` に記録します（35日より古い記録は自動で削除）。予測は直近のペース（5時間枠は直近1時間、週間枠は直近24時間）を延ばしたもので、記録が足りないうちは枠の始まりからの平均ペースを使います。
- **API 料金換算**: ログのトークン数に Anthropic の公開単価（2026-10-06 時点）を掛けた目安です。キャッシュ作成は5分／1時間の区別、fast モードの2倍料金も反映します。サブスクリプションの実際の請求額ではありません。単価は [rinari/pricing.py](rinari/pricing.py) にあるので、変わったらそこを直してください。
- **チャット・Cowork の推定**: 利用上限の % はチャットも含む全体の値ですが、会話ログに残るのは Code と一部の Cowork だけです。Rinari は記録した使用率の区間ごとに「その間の会話ログの料金換算 ÷ 増えた %」を求め、大きい方（80パーセンタイル。チャットを使った区間は % だけ増えて値が小さくなるため）を Code だけを使ったときの「1% あたりの料金換算」とみなします。枠の使用率からこれで説明できる分を差し引いた残りを、チャットなどの利用と推定します。週間枠は区間が集まりにくいので、5時間枠の値と、両方の枠の増え方の比から換算します。枠の減り方が料金換算にほぼ比例するという前提の目安で、Code だけを使った時間帯の記録が増えるほど正確になります。
- **今日の目安**: 今日の最初の記録（枠が今日始まったなら 0%）からの残りを、今日の 0時からリセットまでの日数で割った量です。
- **5時間枠の始まる時刻**: 5時間枠は最初に送ったときから5時間です。記録した5時間枠の増え方を時間帯ごとに平均し（平日が3日分以上あれば平日だけ）、0〜23時のどこかで枠を始めておいた場合の枠の並びを試して、いちばん多く使う枠の量が一番小さくなる時刻を探します。今の始まり方より15%以上かつ5ポイント以上下がるときだけ提案します。
- **通知**: 利用上限を取得するたび（5分ごと）に使用率と予測を調べます。同じ枠で同じ通知は一度だけ出し、出した記録を `%LOCALAPPDATA%\Rinari\notify-state.json` に残すので、再起動しても繰り返しません。予測は直近のペース（5時間枠は直近1時間、週間枠は直近24時間）で計算し、記録が足りないうちは予測の通知を出しません。リセットの通知はトレイが30秒ごとに問い合わせるときに調べるので、リセット時刻から1分以内に出ます。しきい値は [rinari/notify.py](rinari/notify.py) の先頭で変えられます。
- **タスクトレイ**は Rinari の中から Windows の API（Shell_NotifyIcon）を `ctypes` で直接呼んで表示します（[rinari/tray.py](rinari/tray.py)）。別のプログラムやスクリプトを起動しないので、追加のインストールは要らず、スマート アプリ コントロールの対象にもなりません。Rinari が終了するとアイコンも消えます。
- **自動起動**（`--startup on`）は、`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` に `pythonw.exe "このフォルダ\rinari.pyw" --no-browser` を書き込みます。
- **会話別**の値は会話全体の合計で、選んだ期間に最後に使った会話を並べます。タイトルは Claude Code で付けた名前、無ければ最初の発言です。
- **キャッシュの節約額**は、キャッシュ読込を通常の入力単価で払った場合との差から、キャッシュ作成の割増し分（5分: 1.25倍、1時間: 2倍）を差し引いた額です。
- Microsoft Store 版の Python では、`%LOCALAPPDATA%` への書き込みが `%LOCALAPPDATA%\Packages\PythonSoftwareFoundation.Python.*\LocalCache\Local\Rinari` に振り替えられます。

## 安全のために

- サーバーは `127.0.0.1` だけで待ち受けます。同じネットワークの他の端末からは見えません。
- `127.0.0.1` / `localhost` 以外の Host ヘッダーの要求は拒否します（DNS リバインディング対策）。
- 終了の操作と通知の受け渡しは Rinari の中だけで行い、HTTP では受け付けません。ブラウザで開いた他のサイトから Rinari を終了させることはできません。
- アクセストークンはブラウザへの応答に含めません。送信先は `api.anthropic.com`（使用状況の取得）と `platform.claude.com`（トークン更新）だけです。
- 画面は外部の CDN などを読み込みません。

## 注意

- Anthropic 非公式の個人製ツールです。Anthropic とは関係ありません。
- 使っている usage API は Anthropic の非公開エンドポイントです。仕様が変わると表示できなくなることがあります。
- 使用割合に入るのは Claude Code（デスクトップアプリの Code タブを含む）の利用と、パソコンに残っている一部の Cowork の利用だけです。claude.ai の通常チャットの利用はパソコンに記録されないため含まれません（「チャット・Cowork の利用」は推定値です）。利用上限の % は claude.ai での利用も含めた全体の値です。
- ログイン情報は Claude Code と共有しています。トークンの更新が Claude Code と同時に起きると、どちらかで再ログインが必要になる場合があります。

Rinari

    推移のグラフは Rinari を起動している間に5分ごとに記録した値です。点線はこれまでのペースが続いた場合の予測です。「この枠で使ったモデル」は会話ログの料金換算で、枠の減り方の目安です。

    Claude Code（デスクトップアプリの Code タブを含む）の会話ログから集計しています。claude.ai の通常チャットは含みません。料金換算は同じ量を API で使った場合の目安（USD）で、実際の請求額ではありません。CSV は選んでいる期間の日別・モデル別・プロジェクト別の集計です。

    モデル キャッシュ読込率 入力 キャッシュ作成 キャッシュ読込 節約額

    キャッシュ読込率は、モデルに渡した入力のうちキャッシュから読んだ割合です。節約額は、キャッシュを使わず毎回すべて入力として送った場合との差（作成時の割増しを差し引いた額）です。

    モデル 応答数 入力 出力 キャッシュ作成 キャッシュ読込 料金換算 割合

    プロジェクト モデルの内訳 応答数 全トークン

    会話 モデルの内訳 最終 応答数 全トークン

    期間の切り替えに関係なく、すべての記録から集計します。値は上の「集計する値」に合わせます。週は日曜日始まりです。

    期間 料金換算 応答数 全トークン 前の期間比

    「今週」「今月」は、先週・先月の同じ日数（今日の分まで）と比べています。

    Rinari は Anthropic 非公式の個人製ツールです。利用上限は非公開の API から取得しているため、仕様が変わると表示できなくなることがあります。
